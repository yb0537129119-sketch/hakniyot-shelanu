# הקניות שלנו — כחול + Cloudflare D1

החבילה משלבת את ממשק הקטגוריות הכחול עם שמירת רשימות בענן דרך Cloudflare Pages Functions ו-D1. חמש המשפחות מופרדות בצד השרת. כל קטגוריה נוצרת כרשימה קבועה לכל משפחה. רענון בין מכשירים כל 12 שניות.

## לפני פרסום
1. ודאו שב-Cloudflare Pages הפרויקט מחובר למאגר GitHub הנכון.
2. Settings → Bindings → D1 database bindings: binding בשם `DB` שמצביע למסד `hakniyot-shelanu-db-2026`.
3. העלו את כל הקבצים והתיקיות שב-ZIP לשורש המאגר (מיזוג, לא תיקייה פנימית).
4. ודאו שהתיקייה `functions/api/` נשמרת בדיוק במיקום הזה. Cloudflare Pages Functions צריכות להיות בשורש הפרויקט.
5. פרסו מחדש ובדקו משני מכשירים.

## אבטחה
סיסמאות אינן נשלחות בקוד HTML/JS; השרת משווה SHA-256 מול hashes בצד השרת. בכל בקשת API נשלחים שם המשפחה והסיסמה ב-HTTPS. זו שכבת הגנה בסיסית, לא מערכת אימות עם session/נעילה נגד ניסיונות. מומלץ להחליף את הסיסמאות לקודים חזקים יותר לפני שימוש רגיש.

אין להשתמש ב-localStorage עבור נתוני רשימות; הנתונים נשמרים ב-D1. אין מחיקת נתונים קיימים.
