# הקניות שלנו — שחזור עיצוב כחול

הקבצים משחזרים את מסך הקטגוריות הכחול לפי צילום המסך שסופק.

## חשוב לפני פרסום
- זהו שחזור חזותי/אב-טיפוס של הממשק.
- רשימות נשמרות כרגע ב-localStorage של המכשיר בלבד.
- סיסמאות המשפחות מוטמעות בקוד הדפדפן ולכן אינן אבטחה אמיתית.
- אין כאן עדיין חיבור API/Cloudflare D1 לסנכרון בין מכשירים. אין לפרסם כגרסה סופית עם ציפייה לסנכרון או פרטיות מאובטחת.
- כדי להשלים את הדרישה המקורית, יש לשלב את ממשק הקטגוריות הזה עם אימות בצד השרת ועם פונקציות D1 הקיימות/המיועדות בפרויקט.

סיסמאות דמו: עמר, בן גיגי, זכאי, עוזר, ינון.
