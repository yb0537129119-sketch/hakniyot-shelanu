# הקניות שלנו — גרסת סנכרון בענן

הקוד שומר רשימות ב-Cloudflare D1 דרך Pages Functions. הוא כולל חמש משפחות, רשימות אישיות, שיתוף רשימה למשפחה אחרת, הוספה/סימון/מחיקת מוצרים ורענון אוטומטי כל 12 שניות.

## התקנה ב-Cloudflare Pages
1. ב-Cloudflare פתחו את פרויקט Pages שמחובר למאגר הזה.
2. תחת Settings → Functions → D1 database bindings הוסיפו binding בשם `DB` ובחרו את מסד הנתונים של האפליקציה.
3. אם עדיין אין מסד נתונים, צרו D1 בשם `hakniyot-shelanu-db`, ואז קשרו אותו ל-binding בשם `DB`.
4. פרסו מחדש את האתר. הטבלאות נוצרות אוטומטית בבקשה הראשונה ל-API.
5. בדקו כניסה מכל אחד משני מכשירים, צרו רשימה, הוסיפו מוצר, ושתפו עם משפחה אחרת.

## בדיקת אבטחה חשובה
בגרסה הזו בחירת שם משפחה היא זיהוי בלבד: כל מי שיודע את שם המשפחה יכול להתחזות אליה. לכן אין כאן אימות PIN אמיתי, ואין להשתמש במערכת למידע פרטי. לפני שימוש משפחתי קבוע מומלץ להוסיף קוד PIN/אימות אמיתי בצד השרת.

## קבצים חדשים
- `functions/api/` — API לרשימות, פריטים ושיתוף.
- `migrations/0001_init.sql` — סכמת D1 שאפשר להריץ ידנית אם רוצים.
