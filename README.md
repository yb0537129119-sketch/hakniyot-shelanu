# הקניות שלנו

אפליקציית רשימות קניות בעברית, מותאמת לנייד.

## חשוב לדעת
הגרסה המצורפת היא אבטיפוס מקומי: הרשימות נשמרות בדפדפן של המכשיר בלבד. בחירת משפחה אינה אימות משתמש, והרשימות עדיין אינן מסתנכרנות בין מכשירים. אין להציג אותה למשפחה כגרסה משותפת פעילה.

כדי להשלים מוצר משפחתי אמיתי יש להוסיף Cloudflare Pages Functions + D1, API לשמירה/שיתוף, ואז לפרוס דרך GitHub ל-Cloudflare Pages. אין להפעיל שיתוף בענן לפני שמחברים את מסד הנתונים.

## פריסה ראשונית של התצוגה
1. צרו מאגר GitHub חדש בשם `hakniyot-shelanu`.
2. העלו את כל הקבצים שבתיקייה למאגר.
3. ב-Cloudflare Pages בחרו Create project > Connect to Git.
4. בחרו את המאגר.
5. Framework preset: None. Build command: להשאיר ריק. Build output directory: `/` או `.` לפי מסך ההגדרה.
6. לאחר הפריסה פתחו את כתובת האתר בטלפון והוסיפו למסך הבית.

## משתמשים שהוגדרו במסך הכניסה
- משפחת עמר
- משפחת בן גיגי
- משפחת זכאי
- משפחת עוזר
- ינון

- Cloudflare D1 database
- Pages Functions API
- סנכרון רשימות בין מכשירים
- שיתוף רשימות בין משפחות
- הרשאות משפחתיות (שם משפחה בלבד הוא זיהוי נוח, לא אבטחה)
